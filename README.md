## 터미널 git bash 명령어
- rm -rf kant/ : kant 내 모든 파일 강제 삭제
- rm -rf . : 현재 폴더의 모든 파일 삭제
- ctrl + l : clear 명령어와 동일

## Git 기초 명령어
### 사용자 등록
- git config --list : git의 설정값 목록 확인 / config(설정)
- git config --global user.email "jdh990315@gmail.com" : git의 글로벌 설정파일에 사용자 계정 등록
- git config --global user.name "JeongDongHee" : git의 글로벌 설정파일에 사용자 이름 등록

### 기초 명령어
- git init : git 초기화
- git status : git 현재상태확인
